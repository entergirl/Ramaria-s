# Ramaria 桌面使用指南

> 版本：3.0
> 适用平台：Windows
> 配套文档：第一次使用请先看[新手引导（3.0）](getting-started.md)（安装准备、三条接入路径与常见问题）；数据外发口径见[隐私说明](privacy-notice.md)；命令行见[CLI 使用指南](cli-user-guide.md)。

---

## 概述

Ramaria（珊瑚菌）是一个本地优先的个人 AI 陪伴记忆系统：对话会持续沉淀为分层记忆与人格画像，对话、记忆与人格数据存在本机 SQLite，日志与配置也在本地，无遥测；选择 LM Studio 本地模型时可完全离线运行。

核心能力：

- **分层记忆**：对话自动生成摘要（L1）、事件（L2）、性格画像（L3）与知识事实，可逐层追溯来源。
- **混合检索**：向量 + BM25 + 图谱 + 关键词四通道融合（RRF），按人格与衰减重排后注入对话。
- **人格系统**：自动推断人格特征；可从预设文件导入人格（persona.toml 超集 / SillyTavern 角色卡），手工写入的画像不被自动覆盖。
- **主动对话**：按节拍判定、四源选题与 AI 判据决定是否开口，配打扰控制（免打扰 / 日上限 / 冷却 / 退避 / 逐人格三态开关）。
- **多入口**：桌面应用、CLI、MCP 客户端（stdio），以及 QQ / Telegram 社交通道；本地对话、MCP 与社交三条路径共用同一份本地数据。
- **导入**：QQ 聊天记录（QQChatExporter v6.x JSON），快速 / 深度两种模式，支持中断续跑。
- **隐私**：数据全本地；线上模型按 provider + 地址粒度首次确认；API Key 只进 Windows 凭据管理器。

## 安装

### 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 11 / Windows 10 1809 及以上（64 位） |
| 内存 | 8 GB 及以上推荐 |
| 磁盘 | 安装包约 13 MB（内嵌 WebView2 引导程序）；本地嵌入模型约 100 MB（默认 `bge-small-zh-v1.5`，可选 `Qwen3-Embedding-0.6B` 约 1.2 GB）；LM Studio 对话模型需在 LM Studio 中单独下载 |
| 运行环境 | 安装包内置 WebView2 引导程序（在线安装；系统已具备时跳过），无需手动安装运行时 |

### 安装步骤

1. 下载 `Ramaria_3.0.0_x64-setup.exe`（CPU 包；带 NVIDIA 显卡可选择 CUDA 包，二者只能装一个，覆盖升级）。
2. 双击运行安装程序（中文引导），选择安装位置（默认当前用户目录，无需管理员权限）。
3. 完成安装后启动 Ramaria；首次启动进入三步配置向导。

> 安装包**不附带** `ramaria` 命令行程序，MCP 接入需另行准备 CLI 并加入 PATH（见「MCP 接入」）。

## 首次配置

首次启动为全屏向导（宽自适应、上限 800；一屏显示），完成后直接进入主界面，不等待索引构建。

### 第 1 步：对话模型

| Provider | 类型 | 说明 |
|----------|------|------|
| **LM Studio** | 本地 | 免费、数据不出本地；需先在 LM Studio 中启动服务并加载模型，默认地址 `http://localhost:1234/v1` |
| **DeepSeek** | 云端 | 需 API Key；支持思考模式（默认开启） |
| **OpenAI** | 云端 | 需 API Key |

- 填入地址 / 模型 / API Key 后点「测试连接」：**先保存再探测**，失败会就地给出原因。
- 线上 provider 首次使用需按「provider + 服务地址」确认隐私（同一组合只需确认一次；换地址需重新确认）。
- 图片理解能力在向导中勾选「模型支持图片理解」（默认关闭；关闭时导入与社交图片不做理解）。

### 第 2 步：嵌入模型

- 选择本地嵌入模型目录（safetensors），点「校验模型路径」只探测、不写入；设置页中的「校验向量模型」同样只探测，保存后才热加载。
- **可跳过**：跳过则进入降级状态，向量通道关闭、以 BM25 + 图谱 + 关键词召回，其它功能不受影响；之后可在设置中补配。

### 第 3 步：确认并进入

- 回显 provider / 地址 / 模型（API Key 不回显），第 3 步内的隐私确认行内块完成线上确认。
- 保存后进入上次所在视图；索引在后台构建（顶部横幅显示进度），首条消息用降级召回，不阻塞。
- 冷启动若发现「只点过测试连接、未走完向导」，会回到向导并回显已保存配置。

## 界面与导航

Ramaria 3.0 **没有侧边栏和页眉**：全部导航由一个常驻的圆键完成。

- **核心键 🪸**：单击展开 / 收起，拖拽可移动，双击回到位置预设；展开时向左倾倒 45°。
- **视图键**：对话 / 记忆 / 人格 / 规则 / 导入；解锁调试后增加「调试」。标签在键右侧并与键垂直居中，悬停时键微移、标签向右浮出；贴右缘时镜像到左侧。
- **功能键**：向上 = 主题（浅色 / 深色），向右 = 设置，向下 = 品牌（关于）。
- **位置预设**：底中（默认）/ 左上 / 右上 / 左下 / 右下，可在「设置 → 数据与系统 → 界面与导航」切换；全屏页（首次配置 / 错误页）只显示主题与品牌两键。
- **收起**：Esc 或点击遮罩；键盘可在核心键与子键之间遍历（Enter / Space 等价点击）。
- **关于浮层**：版本号、仓库地址（点击复制）、License、更新状态与「检查更新」、调试开关；打开时先收起导航，Esc / 遮罩 / 关闭键关闭。

主界面内容以居中工作台呈现（上限 880 宽）；窗口默认 1200×820，最小 640×480。

## 对话

### 布局

- 对话区上限 **800×600** 居中漂浮；小窗时铺满可用高度，圆键由用户拖动避让。
- 头部约 76px：46px 头像（点击展开会话卡片）、人格名与标签（默认人格 / 只读 / QQ / 群聊 / 导入 / 新会话）、状态（「对话中 · 本地推理」，流式时粉色脉冲 +「正在生成…」）、「保存对话」描边键（仅可保存时出现）。
- 消息区内部滚动，顶 / 底渐隐；输入区 60px（只读或导入会话替换为 44px 只读条）。

### 发送与流式

- Enter 发送、Shift+Enter 换行；流式期间输入禁用，回复逐字显示并带光标。
- **纯文本渲染**：正文不做 Markdown 解析，保留换行；`**强调**`、代码块、链接按原文显示（安全优先）。
- `||` 是「分多次说」的分隔符：渲染为多个气泡，随回复一次性出现；落库内容不变，标记本身不显示。约 0.8 秒的间隔只用于社交平台出站拆条，不作用于桌面本地渲染。
- 空回复按错误处理：提示可重试，不留空气泡、不写入记录。

### 会话卡片

- 点头像展开，顶部「会话 / 新建」，列表独立滚动，底部固定搜索。
- 按「今天 / 更早 / 空对话」分组；行含头像、名称、来源标签（默认人格 / QQ / 群聊 / 导入）、最后一条预览、时间、未读徽标；当前会话高亮。
- **空对话**：还没有本地会话的人格（不含本人与 QQ 导入联系人）在列表里预留「空对话」入口；点开即以该人格开新对话。
- **「新建」以默认对话人格开局**：人格页「设为默认对话人格」选中的角色就是新会话的初始目标。
- 点外部 / Esc / 再点头像收起；展开时消息列与横幅右移 308px（窄窗由用户拖动圆键避让）。
- **新建会话不预落库**：首次发送才创建。
- **未读**：打开会话即标记已读（打开会话、记忆跳转、启动恢复、通知定位、回复完成五处入口），托盘徽标同步刷新。

### 保存与已关闭会话

- 「保存对话」关闭当前会话并触发记忆管线（L1 摘要，可能级联 L2 / L3），界面自动开始新对话。
- 已关闭会话只读：隐藏输入区，横幅只保留「开始新对话」一个动作。

### 撤回

- 自己发送的消息悬停出现「撤回」：仅本地会话、仅本人、2 分钟窗口内可用；失败时直接给出原因。
- 被撤回的消息折叠为居中系统条「消息已撤回」。
- 社交平台撤回事件由通道识别：未参与过回复的消息内容不再进入上下文，已参与的保持上下文连贯（Telegram Bot API 不提供撤回事件）。

### 图片与主动消息

- 输入区图片键 → 选择文件（初始目录 = 发图目录）→ 插入占位符卡片并后台识别；选择文件期间只禁用、不转圈。
- 图片卡三态：普通 / 长图 / 失败；读取优先用本地缓存，其次回导出目录或按指纹反查（单张上限 20MB）。
- 主动消息带「主动消息 · HH:MM」标签，可在会话中续写或新建会话，与用户消息同权参与记忆回流。

### 社交与导入会话

- QQ / Telegram 会话在桌面**仅可查看**：隐藏输入区，提示「该会话来自社交平台，仅可查看；回复请在对应平台进行」。
- 群聊与导入历史按日志视角展示：消息在左侧按序排列，能取到发言人时显示首字头像与昵称（含自己与机器人），不再区分左右气泡；`@` 渲染为高亮 chip。
- 导入会话同样只读（来源标签「导入」），横幅提供「开始新对话」。

## 记忆

点击圆键「记忆」进入。页面定高 800×600，工具栏、页内横幅与页签固定，卡片区在内部滚动并在上下边缘渐隐。

### 工具栏与人格筛选

- 左侧头像（38px）点开后展开人格卡，再点收起；展开 / 收起为 240ms 过渡（减弱动效时直接切换）。
- 人格卡列出现有人格与分类标签；切人格重新加载该人格缓存，切页签保留旧内容。
- 右端「深度处理导入的消息」手动触发 L2→L3 级联。

### 四个页签

| 页签 | 内容 |
|------|------|
| **L1 摘要** | 摘要、时段 / 氛围 / 参与人数、关键词、效价与强度、相对时间；「查看对话」跳回对话，「详情」展开来源摘录、采集信息、关联 L2 |
| **L2 事件** | 置信度 / 共享度 / 日期、摘要、效价 / 表现 / 态度、关键词、证据数量与支持 / 矛盾 / 中性分布；「展开证据」查看可得字段 |
| **L3 性格** | 画像状态（数据不足 / 初步 / 可信）与样本量；特质卡含置信度、说明、证据量、触发与抑制条件；「展开证据」查看证据链与重载画像 |
| **知识** | 只读事实、来源 L2、置信度、更新 / 创建日期、关键词；「更新历史」查看版本链与来源证据 |

- 详情同时只开一张，切页签自动收起；不弹窗、不覆盖其它卡。
- 跨层跳转只切页签：L1 ↔ L2、L3 → L2、知识 → L2；L1「查看对话」跳到对话页并可返回记忆（保留人格 / 页签 / 滚动位置）。
- 时间一律按**发生时间**展示（导入的历史对话按真实时间排序，与导入先后无关）。
- 索引未就绪 / 构建中 / 失败时，页签上方显示页内提示条（构建中带百分比与底边进度），浏览不阻塞。

## 人格

### 列表

- 人格卡：头像、名称、类型标签（user / rama / char / anim / oc / hist）、来源、描述预览、更新时间、默认标记。
- 工具栏与空状态均提供「导入预设」入口；加载 / 空 / 错误三态齐备。

### 详情与编辑

- 横幅 60px：返回描边键、昵称与类型 / 默认标记同行、保存主按钮；滚动时吸附顶部。
- 三卡：基础资料 / 画像 / 描述（卡内距 18、卡间 8、网格 10）；描述框吃掉剩余高度。
- 可编辑名称（必填）、描述、头像：头像经文件选择 → 中心裁方形 192×192 JPEG → 以 data URI 存入；保存后对话页头部的姓名与头像同步更新。
- 「设为默认对话人格」是真设置：会话卡片「新建」、未指定人格的对话请求（CLI / MCP）与外部接入（QQ / Telegram 绑定未覆盖时）都以它为默认；「重载性格画像」触发该人格 L2→L3 重算。

### 预设导入

- 支持 `persona.toml` 超集（`[persona]` / `[traits]` / `[[facts]]` / `[[examples]]` / `[[behavior_rules]]` / `[prompt]`）与 SillyTavern 角色卡（`.json` / `.png`）。
- 流程：选文件 → 预览（UID、模式 create / merge、四类计数、拆解开关与隐私确认）→ 确认写入 → 结果提示。
- **导入不会失败**：自由文本块无法拆解或隐私未确认时，原文保留在人格配置里，人格照常建成。
- **Manual 保护**：导入写入的画像带手工标记，自动推断不覆盖、不删除、不挂证据；需要接管时用 CLI `ramaria persona allow-inference <uid>`。

### 导出

- 先选保存位置再执行；「含对话示例」默认关闭，开启时会提示「含真实对话片段」。
- 导出不含证据链与会话原文；成功提示写入路径与统计。

### 提示词查看器

- 进入详情即读取静态段；折叠态 76px 预览 + 字数页脚；展开后按整段阅读，上两卡压缩为摘要行。
- 两档：静态段 / 全量（含记忆召回，必须填写示例输入）。只读——不建会话、不写库、不调 LLM。

## 规则

- 内容区上限 800×600 居中；列表与详情共用同一舞台，溢出区域内滚动并上下渐隐。
- **列表**：人格筛选抽屉展开时占满内容高度、卡片转单列；规则卡双列，单数时最后一条跨两列；卡含来源（手工 / 自动）、启停、规则文本、情境关键词、置信度 / 稳定性 / 情感强度。
- **详情**：左右两列等高（规则卡 + 证据链 / 参数与统计），各自内滚；规则文本与禁忌词在详情编辑，「保存」在启用开关左侧；未保存返回需确认；保存后转为手工强锚点。
- 证据链按「规则 → 事件 → 摘要」脱敏展示，不显示原文全文。
- **不提供**：删除规则、重新推断（后端无对应命令）；候选规则标注「仅参数注入」，文本可留空、只改禁忌词。

## 导入

支持 QQ 聊天记录（QQChatExporter v6.x JSON，流式解析大文件）。

### 四步向导

**1. 选择**：文件行与模式卡同屏常驻（不设「未选文件」空态页）。未选时显示「未选择文件」与格式说明；已选时显示文件名与完整路径，行内可「更换文件」。字段含模式（默认快速）、导入侧、切割间隔（默认 10 分钟）、双方 Persona 名称 / UID、对话类型。底部唯一「分析文件」，未选文件时禁用。

**2. 预览**：统计卡（原始消息 / 成功解析 / 降级 / 跳过 / Session）+ 信息列（导出者 / 对方、时间范围、Session 切割、导入模式、对话类型）；解析失败停在本步，可重试或更换文件。

**3. 执行**：阶段条（快速 = 图片理解 / 摘要；深度再 + 事件 / 画像）+ 阶段内百分比 + 已完成 / 总数 + 剩余时间（后端估算优先、线性兜底）；L0 写入阶段无进度事件时用不定进度。离开页面不中断，回来仍在执行则回到本步；执行中锁定步骤。

**4. 完成**：统计 +「导入另一个文件」「查看导入消息」「前往记忆页面」+「继续处理」。L1 失败给出警告与重试；索引并行构建时提示「索引后台构建中」。

### 模式与去重

| 模式 | 链路 | 适合 |
|------|------|------|
| 快速导入 | L0 消息 → L1 摘要 | 保留记录、快速完成 |
| 深度导入 | L0 → L1 → L2 事件 → L3 画像 | 完整分析聊天内容、提取人格 |

- 重复消息自动去重：同一文件内去重 + 跨文件按导入指纹跳过已导入消息。
- 图片：开启图片理解后对图片生成描述供摘要与展示；未开启、能力不可达或线上未确认时附件保持「待处理」，可稍后续跑。

### 继续处理

导入完成但仍有附件未理解或摘要缺失（中途关闭、图片理解当时不可用）时，在导入页点「继续处理」：

- 流程：重扫待处理附件（含按指纹从导出目录反查）→ 补跑缺失 L1 摘要 → 补触发深度级联；已完成的自动跳过，可重复执行。
- 需选择导出目录（对话框选择即授权）；取消选择时二次确认，可选择「仅补摘要与画像」（跳过附件回补）。
- 进入页面时会检测待办规模（待处理 / 已跳过附件、缺摘要会话），据此判断是否需要续跑。

## 设置

设置页为两级菜单：一级「基础设置 / 进阶设置」（进阶在解锁调试后出现），二级为子页 / 类；深链 `#/settings/{scope}/{section}`；每次从其它视图进入重置为「模型与检索」，同次停留内切换保留。

### 基础设置（5 子页 / 12 卡片）

| 子页 | 卡片 | 要点 |
|------|------|------|

保存口径：除消息名单外均为区块级显式保存；保存中锁定控件，失败回滚并在卡内或 Toast 提示；「恢复默认」只填默认值并标脏，需再点保存。

## 调试（解锁后）

在关于浮层打开「调试」开关后，圆键出现「调试」视图，设置页出现「进阶设置」。三个只读页签：

- **关键词池**：三态统计与词条列表；待确认别名可确认合并或驳回（与 CLI `ramaria keyword` 同一状态机）。
- **说话风格**：样本量、统计状态、规则来源、基线版本、五维统计。
- **评估产物**：选择目录 → 文件列表 → 单文件解析（不触发后端运行）。

调试关闭时视图消失，若正停留则退回对话；「判据理由」等无数据源的面不渲染，避免伪数据。

## 主动对话

Ramaria 可在你未开口时主动发起对话：选题器从记忆里挑选话题，经打扰控制后投放为系统通知与应用内消息。

### 触发与克制

- **人格级开关**：默认「自动」——与某人格**真实对话过一次**后自动开启（导入的历史不计）；可在「设置 → 主动对话 → 主动消息名单」手动设为开启 / 关闭。从未对话过的人格不打扰；`user` 人格不参与。
- 运行期按节拍（默认 5 分钟）判定：距上次对话空闲 ≥4 小时、不在免打扰时段（默认 `22:00-08:00`）、该人格当日未达上限（默认 3 条）、全部人格合计未达全局上限（默认不限）、距上次投递超过冷却（默认 8 小时）、未处于连续未回应退避、已过启用宽限（默认 3 天）。
- 开口前由 AI 判据决定是否开口 / 聊什么 / 角度与语气；判据不可用时保持安静。
- 按作息软加权（低活跃时段更克制，样本不足不启用）；话题来源：高显著事件 / 未了结的关心 / 时间节点 / 行为习惯，同一话题在冷却窗口内不重复。
- **早安问候**：按起床时间窗口（默认 ±45 分钟）每日至多一次候选；**近期状态**：把最近一两周的心情氛围带进内容（中性时不添加）。

### 收到消息后

- 系统通知显示预览；点击通知聚焦主窗口并定位到会话（安装版注册通知身份，点击可靠）。
- 应用内出现带「主动消息」标签的气泡；会话卡片显示未读，打开即已读。
- 主动消息同权参与记忆回流（摘要 / 事件 / 画像 / 风格）。

### 调整

基础页管总开关、日上限、最小空闲、免打扰、冷却与消息名单；判据与选题、时段建模、问候与近期状态在进阶「主动对话」类。免打扰 / 上限 / 冷却 / 退避为硬闸门，作息为软信号。

## 社交平台接入

把 Ramaria 接入 QQ 或 Telegram，消息与图片同权进入记忆管线。**默认全部关闭**，需在「设置 → 社交与接入」显式开启；连接随桌面应用启停。

### QQ（NapCat + OneBot v11）

1. 安装并登录 NapCat（按其官方文档完成扫码 / 验证）。
2. 打开 NapCat WebUI（默认 `http://127.0.0.1:6099`）→「网络配置」→ 新建 **WebSocket 服务器**：端口 `3001`（与默认一致）、消息格式 `array`，保存并启用。
3. 若服务设置了 access token，在「社交平台接入」卡的「平台凭据 → QQ Token」填入同一 token（未设置留空）。
4. 打开通道总开关与 QQ，点「启动」，状态显示「已连接」即就绪。
5. 私聊直接回复；群聊只有 **@ 它** 或 **回复它的消息** 才响应。

> 风控提示：NapCat 等协议端属非官方第三方实现，登录 QQ 存在账号被限制 / 冻结风险；建议使用小号、避免高频发送与批量操作。Ramaria 与 NapCat / NapNeko 无隶属关系。

### Telegram（Bot API）

1. 与 [@BotFather](https://t.me/BotFather) 对话，`/newbot` 创建并取得 bot token。
2. 在「平台凭据 → Telegram Bot Token」填入，打开通道总开关与 Telegram 通道，点「启动」。
3. 给 bot 发一条消息（或拉进群），收到首条消息后自动建立绑定。
4. 群聊同样只响应 @ 或回复；需要主动说话时在该绑定行打开「允许主动」（还需人格三态放行）。

> bot token 等价于 bot 的完全控制权，请勿分享；泄露可在 BotFather 中 `/revoke`。

### 绑定与白名单

- 每个外部会话（私聊 / 群聊）对应本机侧人格 + 启用开关 +「允许主动」。
- 收到消息自动建档但**默认不放行**：对该会话「放行」后才处理；未放行的消息不入库、不回复。
- 配置或凭据改动后需**重新启停通道**生效（不热重载）；凭据存 Windows 凭据管理器，界面不明文回显。

### 会话行为

- 桌面客户端内社交会话**只读**（回复请回平台）。
- 收到的图片下载到本地（≤20MB）并写入图片缓存，桌面可直接看到原图；"先理解后回复"，理解超过 20 秒按占位符先回复、后台补理解。
- 回复中的 `||` 拆为多条分次发送（间隔约 0.8 秒，单条最多 5 段）；QQ 撤回按平台事件处理（Telegram Bot API 不提供撤回事件）；表情 / 贴纸折叠为 `[表情]` 参与对话；表情资产经 CLI `ramaria sticker` 管理，命中时随回复发图、未命中退回纯文字。
- 主动投放需多层开关同时放行（通道总开关 → 绑定允许主动 → 人格三态）；平台发送失败不计入投递冷却。

## MCP 接入

把 Ramaria 的记忆与人格接入支持 MCP 的外部客户端（CodeBuddy / Trae / DeepSeek Harness 等）。

- **前置**：桌面安装包**不随带** `ramaria` CLI。需另行获取 CLI 并加入 PATH，否则客户端拉不起服务。
- **开关**：MCP 总开关默认关闭；保存后需在客户端重连（重启）才生效。
- **状态与库路径**：卡片展示配置开关、最近外部活动与活跃会话数、当前库路径（可复制）。
- **客户端配置片段**：一键复制通用 `mcpServers` JSON 与 DeepSeek Harness patch；片段包含 `--db <库路径> mcp serve`（库路径未知时退化为最小片段），避免客户端按工作目录打开另一份库。
- **人格白名单 / 原文与写入开关**：限制可见人格（默认全部）、控制原文块是否出端、是否允许外部写入回流。
- **隐私提示**：挂载后被检索的记忆与回流内容会随对话发送给该客户端所用的模型。

## 系统功能

### 系统托盘

- 启动后常驻；有未读时图标右上角叠加数字（超过 99 显示 `99`），悬停显示未读总数。
- 右键菜单：显示 / 隐藏 / 退出。退出不会强制封存当前会话；消息已落库，下次启动后由空闲检查按最后消息时间补做封存与 L1 摘要。要立即生成摘要，请先在对话页点「保存对话」。

### 关闭窗口

点击窗口关闭按钮弹出确认：**最小化到托盘** 或 **退出 Ramaria**（该弹窗不响应 Esc 与遮罩点击，5 秒无响应时兜底隐藏到托盘，避免误关后窗口不可见）。

### 桌面通知

- 窗口不可见时，回复完成弹出 Toast（显示预览）。
- 主动消息通知标题为人格名、正文为消息预览；点击聚焦主窗口并定位会话。

## 数据与隐私

### 本地数据

```
%APPDATA%\Ramaria\data\
├── ramaria.db             # SQLite：会话 / 消息 / 分层记忆 / 人格 / 知识 / 文档向量 / 设置
├── config.toml            # 非敏感配置
├── logs\ramaria.log       # 运行日志（每次启动覆盖）
├── image_cache\           # 图片缓存（可清理）
├── stickers\              # 表情资产（CLI 添加）
├── outgoing\              # 本地发图目录（可在设置中改指一个自定义目录）
└── personas\              # 预留目录；人格定义随安装包 resources/config/personas 分发
```

- 数据目录可用 `RAMARIA_DATA_DIR` 覆盖；2.x 的 `assistant.db` **不会被读取或删除**，可与 3.0 库并存。
- 删除全部记忆 = 关闭应用后删除 `data\ramaria.db` 并重启。库内人格记录随库清空；随包人格定义会在下次配置 / 重载时重新注册。当前界面不提供单独删除人格。

### 导出与诊断

- 「数据管理」导出 JSON（带版本信封，与 CLI 同结构）/ Markdown（人类可读）：内容为会话与消息，不含 L2/L3、知识、人格定义与向量；无可导出数据时不写文件并提示。需要完整备份请复制整个 `data\` 目录。
- 「诊断与更新」导出诊断包：日志 + 配置 + 系统信息，导出前二次脱敏；API Key 永不入包。
- 清理图片缓存显示文件数与占用空间，不影响原图与记忆。

### 隐私要点

- 数据全本地、零遥测；使用本地模型时可完全离线运行（检查更新、社交接入等联网功能需主动开启）。
- 线上模型按 provider + 地址首次确认；未确认时对话 / 图片理解 / 预设拆解均不发起。
- 日志不记原文全文、LLM 原始响应与 API Key；API Key 只进 Windows 凭据管理器。
- 预设导出默认不含对话示例；开启「含对话示例」会提示含真实对话片段。
- 详见[隐私说明](privacy-notice.md)。

## 故障排除

| 现象 | 处理 |
|------|------|
| 首次配置「测试连接」失败 | 确认 LM Studio 已启动并加载模型、地址为 `http://localhost:1234/v1`；云端检查 API Key 与网络；错误会就地显示原因 |
| 界面提示「模型不可用」/ 降级 | 设置 → 模型与检索检查 provider 与地址；线上 provider 需完成隐私确认 |
| 顶部长期显示「索引构建中」 | 首次启动或换模型后属正常，进度在横幅；可在「数据与系统 → 诊断与更新」查看索引状态并重建 |
| 「索引构建失败」 | 多为嵌入模型路径无效或显存不足；重新校验向量模型、调小 `embed_batch_size`（进阶 → 索引与 BM25）后重建 |
| 记忆页提示召回暂不含最新记忆 | 索引未就绪 / 构建中，浏览不受影响；等待构建完成或手动重建 |
| 模型路径校验失败 | 选择包含 safetensors 与 config 的模型目录；「校验向量模型」只探测，不写入 |
| 图片显示为占位或空白 | 本地缓存被清理、图片未下载或原图已删除；社交图片需下载成功后才可看；导入图片可点「继续处理」回补 |
| 导入中途中断 / 摘要缺失 | 导入页「继续处理」，选择导出目录续跑（可只补摘要与画像） |
| 社交消息无回复 | 检查通道是否启动、绑定是否「放行」；群聊需 @ 或回复；凭据改动后需重新启停通道 |
| MCP 客户端召回为空 | 客户端配置片段需含 `--db` 库路径；确认 `ramaria` 在 PATH；保存开关后重启客户端 |
| 调试项看不到 | 在关于浮层打开「调试」开关（即时生效），无需重启 |
| 想彻底重来 | 关闭应用 → 备份 / 删除 `%APPDATA%\Ramaria\data\ramaria.db` → 重启重新配置与导入 |
