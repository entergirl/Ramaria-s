# Ramaria 桌面使用指南

> 版本：2.0  
> 适用平台：Windows

## 概述

Ramaria 桌面应用是一个本地运行的个人 AI 陪伴记忆系统。具备以下核心能力：

- 💬 **智能对话**：连接 LM Studio 本地模型或 DeepSeek/OpenAI 云端 API
- 🧠 **分层记忆**：自动从对话中提取摘要（L1）、事件（L2）、性格画像（L3）
- 🎭 **人格画像**：自动推断人格特征，LLM 以该人格身份对话
- 🔍 **混合检索**：向量 + BM25 + 知识图谱 + 关键词镜像多通道融合（RRF 倒数排名融合）
- 📥 **QQ 聊天导入**：导入历史 QQ 聊天记录，快速或深度模式
- 👥 **人格管理**：查看、编辑人格信息，设置默认对话人格
- 📊 **诊断导出**：一键打包日志/配置/系统信息用于故障排查

## 安装

### 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 11（推荐）/ Windows 10 |
| 内存 | 8 GB+ 推荐 |
| 磁盘 | 200 MB（不含模型下载） |
| 运行环境 | 无需额外运行时 |

### 安装步骤

1. 下载 `Ramaria_2.0.0_x64-setup.exe` 安装程序
2. 双击运行安装程序（中文引导）
3. 选择安装路径（默认 `%LOCALAPPDATA%\Ramaria\`）
4. 完成安装，桌面出现快捷方式

**注意**：安装包不含 LLM 模型，模型需单独下载（LM Studio 内下载或使用云端 API）。

## 首次配置

首次启动时进入全屏配置向导，完成后自动进入对话界面。

### 步骤 1：选择 LLM 后端

| Provider | 类型 | 说明 |
|----------|------|------|
| **LM Studio** | 本地 | 免费，需自行下载模型，数据不出本地 |
| **DeepSeek** | 云端 | 需 API Key，性价比高 |
| **OpenAI** | 云端 | 需 API Key，功能全面 |

### 步骤 2：配置连接

- **LM Studio**：确保 LM Studio 已启动并加载模型，默认地址 `http://localhost:1234/v1`
- **DeepSeek / OpenAI**：输入 API Key（保存到 Windows 凭据管理器，不写入配置文件）

### 步骤 3：确认并完成

系统自动初始化数据库、注册人格文件、验证后端连接。配置完成后进入对话主界面。

## 对话（主界面）

### 发送消息

- 底部输入框输入消息，按 `Enter` 发送，`Shift+Enter` 换行
- 助手回复流式逐字显示，带打字光标
- 流式回复期间输入框禁用，显示"正在生成…"

### 会话管理

- 聊天页眉显示当前对话人格（头像 + 名称 + 状态指示），右侧为「📋 历史」与「💾 保存对话」按钮
- 点击「📋 历史」展开左侧会话抽屉：列出历史会话（活跃 / 已关闭 / 导入标签区分），点击切换会话
- 已关闭会话显示关闭时间，只读不可续写
- **保存对话**按钮：关闭当前 session 并触发记忆管线（L1 摘要 → 可能触发 L2/L3），前端不清屏，自动开始新对话

### 已关闭会话（只读）

- 查看已关闭 session 时隐藏输入框，显示"此对话已关闭"提示
- 提供"开始新对话"按钮快速开始新的会话

### 人格选择

- 输入框上方选择当前对话人格（默认 `rama-0001`）
- 不同人格使用不同的 System Prompt 和记忆过滤

### Markdown 支持

助手回复支持 Markdown 渲染：标题、粗体/斜体、代码块、列表、链接。输出经过安全过滤，禁止原始 HTML。

## 记忆查看

点击侧边栏 🧠 进入记忆页。按人格筛选，四个 Tab 切换（L1 摘要 / L2 事件 / L3 性格 / 知识）：

### L1 摘要

- Bento Grid 卡片布局，粉色渐变背景
- 每次会话结束后自动生成（手动关闭或空闲 10 分钟自动关闭）
- 显示：摘要文本、氛围、情绪效价、显著性强度条、情境强度
- 点击卡片展开完整内容

### L2 事件

- 蓝色标记事件列表
- 从多段 L1 中自动提取的离散事件
- 触发条件：未吸收 L1 ≥ 5 条，或最早未吸收 L1 超过 7 天
- 点击展开：事件详情、置信度、态度描述、关联成员

### L3 性格

- 三层标签云：底色（粉色）、主色调（蓝色）、点缀（灰色）
- 自动从事件中推断生成（Phase A 统计 + Phase B LLM + Phase C 增量更新）
- 触发条件：未吸收事件 ≥ 10 条，或最早事件超过 30 天
- 点击标签查看：含义、证据链、置信度评分

### 知识（只读）

- 展示 persona 的结构化知识事实（`field` 类别 / 事实内容 / 置信度 / 来源 / 版本链）
- 来源为事件抽取与仲裁（`auto_fact_detect` 开启时）或手工写入；**只读，双端均不提供事实删除**
- 事实按 `basic_info` / `personal_status` / `interests` / `social` / `history` / `recent_context` / `speaking_style` 分组展示，历史版本沿版本链折叠查看

## 人格管理

点击侧边栏 👥 进入人格页。管理系统中所有已注册的人格。

### 人格列表

- 卡片网格布局，每张卡片显示：
  - 类型图标（👤 用户 / 🌸 助手 / 💬 角色 / 🎭 动画 / 📖 原创 / 📜 历史）
  - 名称
  - 类型标签（user / rama / char 等）
  - 来源（local / qq 等）
  - 描述预览
  - ⭐ 默认标记
- 默认对话人格显示星标标记

### 人格详情

点击人格卡片进入详情页：

- **基本信息编辑**：可在线修改名称、头像 URL、描述，修改后保存到数据库
- **重载按钮**：触发该人格的 L2→L3 性格推断管线（重新计算性格特征）
- **设为默认**：将该人格设为默认对话人格，后续新对话默认使用

### 人格来源

| 来源 | 创建方式 |
|------|---------|
| `local` | 通过 `personas/*.toml` 文件注册（如默认人格「黎杋枫」） |
| `qq` | QQ 聊天记录导入时自动创建 |
| `manual` | 用户通过 CLI `persona reload` 手动注册 |

---

## 规则管理

点击侧边栏 ⚖️ 进入规则页，管理 persona 自动学习到的行为规则（情境 → 反应）。

- **规则列表**：按 persona 筛选；展示来源（Auto 自动学习 / Manual 手工）、启用状态、情境关键词与规则文本摘要
- **详情**：规则文本（reaction / avoid）、情境关键词、情感强度/主动程度/详细度/正式度参数、置信度/稳定性/证据数
- **启用 / 禁用**：即时生效并持久化（禁用会写 S1 反馈日志）
- **手工编辑**：修改 reaction / avoid（编辑后规则转为 Manual 并写反馈日志，后续自动学习不会覆盖）
- **证据链**：规则 → 事件 → 原文摘要溯源（脱敏展示，不显示原文全文）
- **删除**：破坏性操作，需在弹窗中确认

> 规则页与 CLI `ramaria rule` 同源同能力；**不提供事实删除路径**。

## 调试面板（默认隐藏）

在设置页开启「启用调试（开发者模式）」并重启后，侧边栏出现 🧪 调试页，含三个只读页签：

- **关键词**：keyword_pool 三态分层（规范词 / 别名 / 待确认）与计数；待确认别名可确认或驳回（与 CLI `ramaria keyword` 同一状态机；当前生产侧尚无自动写入待确认别名的路径，该列表可能为空）
- **风格统计**：按 persona 展示五维风格统计、样本量、状态标注（数据不足时显示"数据不足"）与自动生成的风格规则文本
- **评估结果**：选择目录后读取最近一次探针 run / evaluate 产物，展示档位得分、维度聚合、辅助指标与注入闸门语义（只读，不触发后端运行）

## 导入功能

点击侧边栏 📥 进入导入页。支持导入 QQ 聊天记录。

### QQ 聊天记录导入

支持格式：
- **JSON 格式**：QQChatExporter v6.x 导出的 JSON 文件（流式解析大文件；TXT / PCQQ 不在 2.0 范围）

### 三步导入向导

**Step 1 — 选择文件**：
- 点击"浏览"选择一个 QQ 聊天记录文件
- 可选择填写导出者画像名称和对方画像名称（可选，默认自动填充）
- 预览文件基本信息（消息数、时间范围）

**Step 2 — 预览报告**：
- 显示文件格式、消息数量、时间跨度、参与方信息
- 确认后将创建的画像信息

**Step 3 — 选择模式并导入**：

| 模式 | 说明 | 适合场景 |
|------|------|---------|
| **快速导入** | 仅写入 L0 消息，生成 L1 摘要 | 只想保留聊天记录，快速完成 |
| **深度导入** | 写入 L0 消息 → 生成 L1 摘要 → 提取 L2 事件 → 推断 L3 性格 | 希望完整分析聊天内容，提取人格特征 |

- 导入进度在导入页（Step 3）内通过进度条展示
- 快速模式跳过 L2/L3，深度模式走完全管线
- 重复消息自动去重：同一文件内去重 + 跨文件按导入指纹（SHA-256）跳过已导入消息（已实装）

### 深度处理

快速导入后，可在记忆页点击"深度处理"按钮，手动触发 L2→L3 级联，将已导入的对话进一步分析。

## 设置

点击侧边栏 ⚙️ 进入设置页。

### 后端配置

- 切换 Provider（LM Studio / DeepSeek / OpenAI）
- 修改 Base URL
- 输入/修改 API Key（遮蔽显示，保存到 keychain）

### 隐私设置

- 线上记忆注入开关：控制是否将本地记忆注入到云端 API 调用中
- 隐私确认状态：查看/重置各 provider 的隐私确认

### 高级设置（需启用调试）

「高级设置」页签默认隐藏：在诊断与更新卡片中勾选「启用调试（开发者模式）」并**重启 Ramaria** 后出现，内含三路检索、知识、风格、注入预算、层间去重、渐进摘要（B3）、画像升级、utt/examples/bridge、日志等 2.0 配置组（每项标注默认值，支持单项/全部恢复默认）。

> 高级项保存经统一写入口同时写入 `config.toml` 与数据库；`log_full_prompt` 为预留项，当前实现未接线（无论开关如何都不会记录完整 Prompt）。

### 诊断与更新

- **当前版本**：显示 Ramaria 版本号
- **检查更新**：查询 GitHub Release 是否有新版本
- **导出诊断信息**：打包日志 + 配置 + 系统信息 → `.zip` 文件（API Key 与敏感字段已脱敏）
- **启用调试**：开发者模式开关（重启生效，见「高级设置」）

### 数据管理

- **导出 JSON**：导出全部数据（会话、消息、记忆、人格画像）
- **导出 Markdown**：导出人类可读格式
- **重建索引**：重建 BM25 和知识图谱索引（含确认弹窗）

### 关于

- 版本号、许可证、[GitHub](https://github.com/entergirl/Ramaria-s) 链接

### 系统托盘

- 应用启动后托盘常驻
- 右键菜单：
  - **显示**：恢复窗口
  - **隐藏**：最小化到托盘

点击窗口关闭按钮（✕）时弹出确认框：
- **最小化到托盘**：窗口隐藏，应用后台运行

- 窗口不可见时，对话回复完成自动弹出 Windows Toast 通知
- 通知显示回复预览

## 数据与隐私

### 本地数据

- 数据库：`%APPDATA%\Ramaria\data\assistant.db`
- 日志：`%APPDATA%\Ramaria\logs\ramaria.log`
- 人格文件：`%APPDATA%\Ramaria\personas\*.toml`
- 配置文件：`%APPDATA%\Ramaria\config.toml`

### 隐私要点

- **本地模型（LM Studio）**：所有对话和记忆仅存储在本地，不上传任何数据
- **云端 API（DeepSeek/OpenAI）**：对话消息和记忆上下文会发送至对应 API 服务器。首次使用需显式确认隐私，确认记录持久化
- **API Key**：存储在 Windows 凭据管理器，不写入配置文件或日志
- **日志策略**：默认不记录完整用户消息、完整记忆、完整 prompt；用户消息只记录长度等元数据（不落原文）
- **导入数据**：导入的 QQ 聊天记录与本地对话数据同等对待，全部存储在本地 SQLite，不出本地
- **诊断导出**：日志/配置打包时二次脱敏（API Key、敏感字段与个人标识均不外泄）

详见《Ramaria 隐私说明》。

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| LM Studio 连接失败 | 确认 LM Studio 已启动并加载模型，base_url 为 `http://localhost:1234/v1` |
| DeepSeek/OpenAI 401 错误 | API Key 无效或已过期，请在设置中重新输入 |
| 对话无记忆注入 | 检查"线上记忆注入"开关是否开启；确认已有 L1/L2/L3 记忆 |
| 索引异常 | 进入设置 → 重建索引 |
| 数据库损坏 | 删除 `%APPDATA%\Ramaria\data\assistant.db` 后重启，需重新配置和导入 |
| 托盘图标不显示 | Windows 任务栏设置 → 选择哪些图标显示在任务栏上 → 开启 Ramaria |
| 窗口启动慢 | 首次启动需初始化数据库和索引，后续启动应在 1 秒内 |
| 嵌入模型不可用 | 未配置嵌入模型时自动降级为 BM25-only 模式（Degraded 状态），对话功能可用但向量检索不可用 |
| 导入进度停滞 | 大文件导入可能耗时较长，查看导入页进度条；若完全无反应，检查文件格式是否正确 |
| 记忆管线未触发 | session 需手动"保存对话"或空闲 10 分钟后自动关闭才会触发 L1→L2→L3 管线 |
| 窗口隐藏后无法恢复 | 右键系统托盘 Ramaria 图标 → 选择"显示"（含超时保护机制） |
| 需要导出诊断信息 | 设置 → 诊断与更新 → 导出诊断信息 → 选择保存位置 |
