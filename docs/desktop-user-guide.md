# Ramaria 桌面使用指南

> 版本：v1.0  
> 适用平台：Windows

## 概述

Ramaria 桌面应用是一个本地运行的个人 AI 陪伴记忆系统。具备以下核心能力：

- 💬 **智能对话**：连接 LM Studio 本地模型或 DeepSeek/OpenAI 云端 API
- 🧠 **分层记忆**：自动从对话中提取摘要（L1）、事件（L2）、性格画像（L3）
- 🎭 **人格画像**：自动推断人格特征，LLM 以该人格身份对话
- 🔍 **混合检索**：向量检索 + BM25 + 知识图谱三通道融合

## 安装

### 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 11（推荐）/ Windows 10 |
| 内存 | 8 GB+ 推荐 |
| 磁盘 | 200 MB（不含模型下载） |
| 运行环境 | 无需额外运行时 |

### 安装步骤

1. 下载 `Ramaria_1.0.0_x64-setup.exe` 安装程序
2. 双击运行安装程序（中文引导）
3. 选择安装路径（默认 `%LOCALAPPDATA%\Ramaria\`）
4. 完成安装，桌面出现快捷方式

**注意**：安装包不含 LLM 模型，模型需单独下载（LM Studio 内下载或使用云端 API）。

---

## 首次配置

首次启动时进入全屏配置向导，完成后自动进入对话界面。

### 步骤 1：选择 LLM 后端

| Provider | 类型 | 说明 |
|----------|------|------|
| **LM Studio** | 本地 | 免费，需自行下载模型，数据不出本地 |
| **DeepSeek** | 云端 | 需 API Key，性价比高 |
| **OpenAI** | 云端 | 需 API Key，功能全面 |

### 步骤 2：配置连接

- **LM Studio**：确保 LM Studio 已启动并加载模型，默认地址 `http://localhost:1234/v1`
- **DeepSeek / OpenAI**：输入 API Key（保存到 Windows 凭据管理器，不写入配置文件）

### 步骤 3：确认并完成

系统自动初始化数据库、注册人格文件、验证后端连接。配置完成后进入对话主界面。

## 对话（主界面）

### 发送消息

- 底部输入框输入消息，按 `Enter` 发送，`Shift+Enter` 换行
- 助手回复流式逐字显示，带打字光标
- 流式回复期间输入框禁用，显示"正在生成…"

### 会话管理

- **SessionBar**：顶部横向显示会话列表
- 点击切换会话，点击 `+` 新建会话
- 右键会话可删除（需确认）

### 人格选择

- 输入框上方选择当前对话人格（默认 `rama-0001`）
- 不同人格使用不同的 System Prompt 和记忆过滤

### Markdown 支持

助手回复支持 Markdown 渲染：标题、粗体/斜体、代码块、列表、链接。输出经过安全过滤，禁止原始 HTML。

---

## 记忆查看

点击侧边栏 🧠 进入记忆页。按人格筛选，三个 Tab 切换：

### L1 摘要

- Bento Grid 卡片布局，粉色渐变背景
- 每次会话结束后自动生成
- 显示：摘要文本、氛围、情绪效价、显著性强度条
- 点击卡片展开完整内容

### L2 事件

- 蓝色标记事件列表
- 从多段 L1 中自动提取的离散事件
- 点击展开：事件详情、置信度、态度描述、关联成员

### L3 性格

- 三层标签云：底色（粉色）、主色调（蓝色）、点缀（灰色）
- 自动从事件中推断生成
- 点击标签查看：含义、证据链、置信度评分

## 设置

点击侧边栏 ⚙️ 进入设置页。

### 后端配置

- 切换 Provider（LM Studio / DeepSeek / OpenAI）
- 修改 Base URL
- 输入/修改 API Key（遮蔽显示，保存到 keychain）

### 隐私设置

- 线上记忆注入开关：控制是否将本地记忆注入到云端 API 调用中
- 隐私确认状态：查看/重置各 provider 的隐私确认

### 数据管理

- **导出 JSON**：导出全部数据（会话、消息、记忆、人格画像）
- **导出 Markdown**：导出人类可读格式
- **重建索引**：重建 BM25 和知识图谱索引（含确认弹窗）

### 关于

- 版本号、许可证、[GitHub](https://github.com/entergirl/Ramaria-s) 链接

## 系统功能

### 系统托盘

- 应用启动后托盘常驻
- 右键菜单：
  - **显示**：恢复窗口
  - **隐藏**：最小化到托盘
  - **退出**：完全退出应用

### 关闭窗口

点击窗口关闭按钮（✕）时弹出确认框：
- **最小化到托盘**：窗口隐藏，应用后台运行
- **退出 Ramaria**：完全退出

### 桌面通知

- 窗口不可见时，对话回复完成自动弹出 Windows Toast 通知
- 通知显示回复预览

## 数据与隐私

### 本地数据

- 数据库：`%APPDATA%\Ramaria\data\assistant.db`
- 日志：`%APPDATA%\Ramaria\logs\ramaria.log`
- 人格文件：`%APPDATA%\Ramaria\personas\*.toml`
- 配置文件：`%APPDATA%\Ramaria\config.toml`

### 隐私要点

- **本地模型（LM Studio）**：所有对话和记忆仅存储在本地，不上传任何数据
- **云端 API（DeepSeek/OpenAI）**：对话消息和记忆上下文会发送至对应 API 服务器。首次使用需显式确认隐私，确认记录持久化
- **API Key**：存储在 Windows 凭据管理器，不写入配置文件或日志
- **日志策略**：默认不记录完整用户消息、完整记忆、完整 prompt。用户消息最多截断前 80 字符并附哈希值

详见《Ramaria 隐私说明》。

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| LM Studio 连接失败 | 确认 LM Studio 已启动并加载模型，base_url 为 `http://localhost:1234/v1` |
| DeepSeek/OpenAI 401 错误 | API Key 无效或已过期，请在设置中重新输入 |
| 对话无记忆注入 | 检查"线上记忆注入"开关是否开启；确认已有 L1/L2/L3 记忆 |
| 索引异常 | 进入设置 → 重建索引 |
| 数据库损坏 | 删除 `%APPDATA%\Ramaria\data\assistant.db` 后重启，需重新配置和导入 |
| 托盘图标不显示 | Windows 任务栏设置 → 选择哪些图标显示在任务栏上 → 开启 Ramaria |
| 窗口启动慢 | 首次启动需初始化数据库和索引，后续启动应在 1 秒内 |
